# Humanoid G1 runtime assets

This directory contains only the assets required by the PingLab Humanoid tab:

- `g1_custom_collision_29dof.urdf` and the meshes it references
- finalized woven-sensor line geometry and channel mappings under `signals/`
- the upstream Unitree model license

The WeavingMapGenerator source, Blender scripts, generation intermediates,
spreadsheets, caches, previews, and unused robot-model variants are not runtime
dependencies and are intentionally excluded.
